💡 两种数据存储模式说明：

1. 默认本地模式：无需任何配置，数据直接保存在当前设备/浏览器内，100% 隐私安全、离线可用。
2. 云端数据库模式 (Supabase)：配置免费的 Supabase 后，每次记账、记录经期与日程都会秒速自动备份同步到云端，换手机或换电脑登录同一账号即可查看所有数据！

⚡ 双向数据同步操作
📖 怎么免费注册并获取 Supabase 密钥？(点击展开教程)

1. 打开 supabase.com 免费注册一个账号并点击 New Project。

2. 在左侧菜单点击 SQL Editor，点击 New query，将项目根目录下的 database.sql 内容全选复制粘贴进去，点击 Run 执行建表。

3. 在左侧菜单点击 Project Settings -> API，复制 Project URL 和 anon public key，粘贴到上方输入框保存即可！
